# ForgeFit Industrial

This is a NextJS starter in Firebase Studio, optimized for elite performance and industrial-grade fitness strategies.

## GitHub Connection Steps

Follow these steps in your terminal to connect this project to your GitHub account:

1. **Initialize Git Repository**:
   ```bash
   git init
   ```

2. **Stage All Files**:
   ```bash
   git add .
   ```

3. **Create Initial Commit**:
   ```bash
   git commit -m "Initial commit for ForgeFit Industrial"
   ```

4. **Create a Repository on GitHub**:
   - Go to [GitHub - New Repository](https://github.com/new).
   - Give it a name (e.g., `forgefit-industrial`).
   - Click "Create repository" (leave the checkbox for README, .gitignore, and License unchecked).

5. **Link and Push to GitHub**:
   *Replace `<YOUR_GITHUB_URL>` with the URL provided by GitHub (e.g., `https://github.com/username/repo.git`).*
   ```bash
   git remote add origin <YOUR_GITHUB_URL>
   git branch -M main
   git push -u origin main
   ```

## Development

To start the development server:
```bash
npm run dev
```

To start Genkit for AI features:
```bash
npm run genkit:dev
```
